ROUTEMIND - QUICK INSTRUCTIONS
==============================

OPTION 1: AUTOMATED SETUP (RECOMMENDED)
----------------------------------------
bash setup_and_test.sh

This will:
1. Check .env configuration
2. Start all services
3. Wait for database
4. Seed sample data
5. Run all tests

If it asks for AWS credentials and you don't have them yet,
the system will still work without AI explanations.


OPTION 2: MANUAL SETUP
-----------------------
1. nano .env
   Add: AWS_ACCESS_KEY_ID=your_key
        AWS_SECRET_ACCESS_KEY=your_secret
   (Optional - system works without AWS)

2. docker-compose down && docker-compose up -d

3. sleep 30

4. docker-compose exec routing-service python seed_simple.py

5. bash test_api.sh


ADDING AWS CREDENTIALS (FOR AI EXPLANATIONS)
---------------------------------------------
1. nano .env

2. Find these lines:
   AWS_ACCESS_KEY_ID=your_key
   AWS_SECRET_ACCESS_KEY=your_secret

3. Replace with your actual AWS credentials:
   AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
   AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

4. Save (Ctrl+X, Y, Enter)

5. Restart: docker-compose down && docker-compose up -d

6. Wait 30 seconds, then test


SYSTEM WORKS WITHOUT AWS
-------------------------
✅ Route optimization - uses OR-Tools (free, fast)
✅ Distance calculation - Haversine formula
✅ COD constraint enforcement - OR-Tools dimension
✅ Re-planning - OR-Tools re-solve
❌ AI explanations - will show fallback text instead

Only the explanations need AWS. Core routing works fine without it.


TEST COMMANDS
-------------
# Optimize routes (no AI)
curl -X POST "http://localhost:8002/api/v1/optimizer/optimize?hub_id=1&use_ai_explanation=false"

# Optimize routes (with AI)
curl -X POST "http://localhost:8002/api/v1/optimizer/optimize?hub_id=1&use_ai_explanation=true"

# Replan route
curl -X POST "http://localhost:8002/api/v1/optimizer/replan?route_id=1&new_stop_id=5&reason=new_pickup&hub_id=1"


CHECKING LOGS

docker-compose logs -f routing-service

docker-compose logs -f ai-service


TROUBLESHOOTING
---------------
Problem: "No active vehicles"
Fix: docker-compose exec routing-service python seed_simple.py

Problem: Services not starting
Fix: docker-compose down && docker-compose up -d
     docker-compose logs

Problem: AI explanations are fallback text
Fix: This is normal without AWS credentials. System still works!
     To enable: Add AWS credentials to .env and restart.
